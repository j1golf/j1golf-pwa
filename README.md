## GitHub 업로드
1. GitHub에서 새 repository를 만듭니다. 예: `jone-golf`
2. 이 폴더의 모든 파일을 repository에 업로드합니다.
3. Commit 합니다.

## Vercel 배포
1. Vercel 로그인
2. `Add New` → `Project`
3. GitHub의 `jone-golf` repository를 선택
4. Framework Preset은 `Other`
5. Build Command는 비워둡니다.
6. Output Directory도 비워둡니다.
7. Deploy

## 예약 폼
현재 MVP에서는 `예약 신청하기`를 누르면 기본 이메일 앱이 열리고,
입력한 내용이 `jonegolf@qq.com` 앞으로 작성됩니다.

실제 DB 저장/자동 이메일/위챗 연결은 다음 단계에서 서버 기능을 추가하면 됩니다.

## PWA 설치
Vercel의 HTTPS 주소로 접속 후 브라우저의 `홈 화면에 추가`/`앱 설치`를 사용합니다.

## 중요한 디자인 원칙
- 프로젝트 확정 디자인을 기준으로 제작
- 사용자 제공 원본 사진은 얼굴/인물 변형 없이 사용
- 공식 연락처는 위 번호/이메일만 사용
